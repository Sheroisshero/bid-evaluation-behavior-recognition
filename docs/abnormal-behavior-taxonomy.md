# 评标专家异常行为分类体系

> 本文档详细定义远程异地评标场景下专家异常行为的分类体系、检测方法、判定阈值和严重等级，为多模态AI异常行为识别系统提供检测标准。

---

## 一、分类体系总览

系统建立了**5大类、15+小类**的评标专家异常行为分类体系，覆盖视频、音频、系统日志三路检测通道：

| 大类 | 小类数量 | 主要检测通道 | 典型严重等级 |
|------|---------|------------|------------|
| 一、操作手机 | 3 | 视频 | 中 |
| 二、交头接耳 | 3 | 视频+音频 | 中 |
| 三、起身离席 | 3 | 视频 | 低-中 |
| 四、不当言论 | 4 | 音频 | 高 |
| 五、其他异常 | 4 | 日志+视频+音频 | 低 |

---

## 二、第一大类：操作手机

### 2.1 行为定义

评标专家在评审过程中使用手机进行与评审无关的操作，包括但不限于：查看手机、操作手机、使用手机通讯、拍摄评审内容等。

### 2.2 小类细分

| 小类编号 | 小类名称 | 行为描述 | 严重等级 |
|---------|---------|---------|---------|
| 1.1 | 查看手机 | 专家低头查看手机屏幕，持续时间较短 | 低 |
| 1.2 | 操作手机 | 专家持续操作手机（打字、滑动等），与评审无关 | 中 |
| 1.3 | 手机通讯/拍摄 | 专家使用手机通话、发送信息，或拍摄评审现场/投标文件 | 高 |

### 2.3 检测方法

**视频通道：**
- **目标检测**：YOLOv8模型实时检测手机目标，输出手机位置、置信度
- **手部关键点检测**：MediaPipe检测21个手部关键点，判断手部是否与手机交互
- **姿态估计**：检测头部低头角度，低头角度>30°且持续时间超过阈值
- **多目标跟踪**：DeepSORT跟踪手机和人体，关联同一专家的行为

**判定逻辑：**
```
操作手机判定 = 手机目标出现(置信度>0.6) 
            AND 手部与手机区域交互(IoU>0.3) 
            AND 低头姿态(头部角度>30°) 
            AND 持续时间≥3秒
```

### 2.4 判定阈值

| 指标 | 阈值 | 说明 |
|------|------|------|
| 手机检测置信度 | ≥0.6 | YOLOv8输出置信度 |
| 手部-手机交互IoU | ≥0.3 | 手部关键点与手机边界框交集 |
| 低头角度 | ≥30° | 头部相对于正常坐姿的倾斜角 |
| 持续时间 | ≥3秒 | 从行为开始到结束的时间 |
| 单次预警间隔 | ≥60秒 | 同一专家同类行为的最小预警间隔 |

### 2.5 证据固化

检测到操作手机行为时，系统自动固化以下证据：
- 异常行为发生前后各5秒的视频片段
- 行为发生瞬间的高清截图（标注手机位置和手部关键点）
- 行为发生的精确时间戳（开始时间、结束时间、持续时长）
- 涉及专家的身份标识（座位号、跟踪ID）
- 检测置信度和判定依据

## 三、第二大类：交头接耳

### 3.1 行为定义

评标专家之间在非讨论环节进行私下交流，包括但不限于：侧身交谈、未开启麦克风交流、传递口头信息等。在远程异地评标场景中，主副场专家之间的私下交流尤其需要关注。

### 3.2 小类细分

| 小类编号 | 小类名称 | 行为描述 | 严重等级 |
|---------|---------|---------|---------|
| 2.1 | 短暂私下交谈 | 专家之间短暂侧身交流，持续时间较短 | 低 |
| 2.2 | 频繁私下交谈 | 专家之间多次、持续私下交流，影响独立评审 | 中 |
| 2.3 | 未开麦交流/传递信息 | 专家在应开启麦克风的环节未开麦，或通过口型、手势传递信息 | 高 |

### 3.3 检测方法

**视频通道：**
- **多人距离检测**：计算不同专家之间的空间距离，距离<0.5m判定为近距离接触
- **朝向判定**：通过人脸关键点和人体姿态，判断专家是否朝向对方
- **嘴部运动检测**：检测嘴部关键点运动，判断是否在说话
- **麦克风状态检测**：通过系统接口获取麦克风开启状态

**音频通道：**
- **环境音能量检测**：在麦克风关闭时，检测环境音中是否有语音能量
- **声纹分离**：分离不同专家的语音，判断是否有未被麦克风捕获的私下交谈
- **语音活动检测（VAD）**：检测语音活动的时间和持续时长

**判定逻辑：**
```
交头接耳判定 = 两人距离<0.5m 
            AND 互相朝向(朝向角度<45°) 
            AND 嘴部运动(至少一人) 
            AND (麦克风关闭 OR 音频能量异常) 
            AND 持续时间≥5秒
```

### 3.4 判定阈值

| 指标 | 阈值 | 说明 |
|------|------|------|
| 两人距离 | <0.5m | 专家座位之间的空间距离 |
| 互相朝向角度 | <45° | 面部朝向与对方方向的夹角 |
| 嘴部运动幅度 | >阈值 | 嘴部关键点的运动幅度 |
| 持续时间 | ≥5秒 | 私下交流的持续时长 |
| 非讨论时段 | 是 | 排除正常集体讨论环节 |

### 3.5 证据固化

- 异常行为发生前后各10秒的视频片段（含音频）
- 行为发生瞬间的截图（标注两人距离、朝向、嘴部运动）
- 音频波形图和语音活动检测结果
- 麦克风状态记录（开启/关闭、时间戳）
- 涉及专家的身份标识和座位号

## 四、第三大类：起身离席

### 4.1 行为定义

评标专家在评审过程中离开评审座位，包括但不限于：短暂离开、长时间离席、非正常时段离席、频繁离席等。

### 4.2 小类细分

| 小类编号 | 小类名称 | 行为描述 | 严重等级 |
|---------|---------|---------|---------|
| 3.1 | 短暂离席 | 专家离开座位较短时间（<5分钟），如去卫生间 | 低 |
| 3.2 | 长时间离席 | 专家离开座位较长时间（≥5分钟），影响评审进度 | 中 |
| 3.3 | 频繁/非正常时段离席 | 专家多次离席，或在关键评审环节（如打分、讨论）离席 | 中 |

### 4.3 检测方法

**视频通道：**
- **人体检测**：YOLOv8检测评审座位区域是否有人体
- **座位区域判定**：预定义每个专家的座位区域，判断人体是否在座位区域内
- **持续时间统计**：从人体离开座位区域开始计时，到返回座位结束
- **离席频次统计**：统计单位时间内的离席次数

**判定逻辑：**
```
起身离席判定 = 座位区域内无人(人体检测置信度<0.3) 
            AND 持续时间≥30秒 
            AND 非正常休息时段
```

### 4.4 判定阈值

| 指标 | 阈值 | 说明 |
|------|------|------|
| 座位区域无人置信度 | <0.3 | YOLOv8在座位区域的人体检测置信度 |
| 离席持续时间 | ≥30秒 | 从离开到返回的时间 |
| 短暂离席上限 | <5分钟 | 超过则升级为长时间离席 |
| 长时间离席下限 | ≥5分钟 | 触发橙色预警 |
| 离席频次 | ≥3次/小时 | 频繁离席判定阈值 |

### 4.5 证据固化

- 离席开始和返回的视频片段（各5秒）
- 离席期间的监控画面（证明座位无人）
- 离席时间记录（开始时间、结束时间、持续时长）
- 离席时段的评审环节信息（是否在关键环节）
- 涉及专家的身份标识

## 五、第四大类：不当言论

### 5.1 行为定义

评标专家在评审过程中发表违反评审纪律的言论，包括但不限于：核心违禁词、敏感信息泄露、倾向性言论、非正常评价等。这是最严重的异常行为类型，直接影响评审公正性。

### 5.2 小类细分

| 小类编号 | 小类名称 | 行为描述 | 严重等级 |
|---------|---------|---------|---------|
| 4.1 | 核心违禁词与高风险表述 | 发表"放水""抬分""压分""改分"等直接干预评审结果的言论 | 高 |
| 4.2 | 敏感信息泄露 | 泄露"内定""指定""推荐"等倾向性信息，或泄露评审分数、标底等敏感信息 | 高 |
| 4.3 | 倾向性言论 | 发表"这家不行""那家好""肯定行"等带有明显倾向性的评价 | 中 |
| 4.4 | 非正常评价 | 主观臆断、不按评审标准评审、"凭经验选""随便打分"等 | 中 |

### 5.3 检测方法

**音频通道：**
- **语音转文字（ASR）**：Whisper-large-v3中文模型实时转写评审对话
- **违禁词库匹配**：AC自动机多模式匹配，实时检测四大类违禁词
- **声纹分离**：区分不同专家的发言，精准定位违规言论发言人
- **语义理解**：大语言模型辅助理解上下文，区分正常讨论和违规言论

**判定逻辑：**
```
不当言论判定 = ASR转写文本中检测到违禁词(匹配度>0.8) 
            OR 语义模型判定为违规言论(置信度>0.7) 
            AND 发言人为评审专家 
            AND 非正常引用/讨论场景
```

### 5.4 判定阈值

| 指标 | 阈值 | 说明 |
|------|------|------|
| ASR转写准确率 | ≥95% | Whisper中文转写准确率 |
| 违禁词匹配度 | ≥0.8 | AC自动机匹配置信度 |
| 语义判定置信度 | ≥0.7 | 大语言模型语义理解置信度 |
| 首次违规 | 黄色预警 | 首次检测到轻微违规 |
| 重复违规 | 橙色警示 | 多次检测到同类违规 |
| 严重违规 | 红色警报 | 检测到改分、内定等严重违规 |

### 5.5 四大类违禁词库详情

详见：[sensitive-word-library.md](sensitive-word-library.md)

### 5.6 证据固化

- 违规言论发生前后各10秒的音频片段
- 违规言论的文字转写内容（高亮标注违禁词）
- 发言人身份标识（通过声纹识别或麦克风通道定位）
- 违禁词类别和匹配详情
- 语义理解的判定依据和上下文
- 精确时间戳

## 六、第五大类：其他异常

### 6.1 行为定义

除上述四类之外的其他异常情况，包括系统异常、网络异常、操作异常、设备异常等。

### 6.2 小类细分

| 小类编号 | 小类名称 | 行为描述 | 严重等级 | 检测通道 |
|---------|---------|---------|---------|---------|
| 5.1 | 网络异常 | 网络卡顿、画面静止、音频中断、频繁掉线重连 | 低 | 日志 |
| 5.2 | 操作异常 | 异常登录、权限越界、非工作时段操作、批量导出 | 中 | 日志 |
| 5.3 | 设备异常 | 摄像头遮挡、麦克风关闭、终端离线、硬件故障 | 低 | 日志+视频 |
| 5.4 | 肢体异常 | 长时间静止/走神、频繁遮挡面部、非生理动作 | 低 | 视频 |

### 6.3 检测方法

**系统日志通道：**
- **操作日志实时采集**：采集登录、操作、权限变更、数据导出等系统日志
- **规则引擎异常检测**：基于预定义规则检测异常操作模式
- **网络状态监控**：实时监控网络延迟、丢包率、连接状态
- **设备状态监控**：监控摄像头、麦克风、终端的在线状态和工作状态

**视频通道（肢体异常）：**
- **姿态估计**：检测人体姿态变化，识别长时间静止
- **头部运动检测**：检测头部运动频率和视线方向，识别走神
- **面部遮挡检测**：检测手部或其他物体遮挡面部的情况

### 6.4 判定阈值

| 异常类型 | 判定条件 | 预警等级 |
|---------|---------|---------|
| 网络卡顿 | 画面静止≥10秒或音频中断≥5秒 | 黄色（记录） |
| 频繁掉线 | 1小时内重连≥3次 | 黄色（记录） |
| 异常登录 | 非常用IP/非常用时段登录 | 橙色（提醒） |
| 权限越界 | 访问非授权功能/数据 | 橙色（提醒） |
| 批量导出 | 短时间导出大量数据 | 橙色（提醒） |
| 摄像头遮挡 | 画面被遮挡≥30秒 | 黄色（提醒） |
| 麦克风关闭 | 应开启时段关闭≥5分钟 | 黄色（提醒） |
| 长时间静止 | 头部静止+视线偏离≥60秒 | 黄色（记录） |

## 七、异常行为严重等级与预警对应

| 严重等级 | 异常类型示例 | 预警等级 | 处置方式 |
|---------|------------|---------|---------|
| **低** | 短暂离席、短暂查看手机、网络卡顿、设备异常 | 🟡 黄色预警 | 音频提示+侧边浮窗+记录归档 |
| **中** | 操作手机、频繁私下交谈、长时间离席、倾向性言论、操作异常 | 🟠 橙色警示 | 音频警告+中央弹窗+片段回放+提醒主持人 |
| **高** | 手机通讯/拍摄、未开麦传递信息、核心违禁词、敏感信息泄露 | 🔴 红色警报 | 全屏警告+建议暂停+证据包自动生成+通知监管 |

## 八、误报控制机制

为降低误报率，系统设计了多层误报控制机制：

1. **多模态交叉验证**：单一通道检测到的异常需其他通道辅助验证，如操作手机需视频+手部关键点双重确认
2. **上下文理解**：结合评审环节（讨论/打分/休息）判断行为合理性，如讨论环节的正常交流不判定为交头接耳
3. **语义消歧**：违禁词检测结合上下文语义，区分正常引用（如"这个评分标准"）和违规使用（如"给他抬分"）
4. **人工复核闭环**：橙色及以上预警支持人工复核，复核结果反馈用于模型优化
5. **阈值动态调整**：根据不同项目类型、专家构成、评审环节动态调整检测阈值

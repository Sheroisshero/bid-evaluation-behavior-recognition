# 评审疑似异常行为分析报告模板

> 本文档定义远程异地评标结束后系统自动生成的疑似异常行为分析报告的模板结构、字段说明和生成流程，为评审监管提供标准化的事后追溯依据。

---

## 一、报告概述

### 1.1 报告目的

评审疑似异常行为分析报告是系统在远程异地评标结束后，基于全程音视频监控数据、音频敏感词监测记录和系统操作日志，自动生成的结构化分析报告。报告旨在：

- 客观记录评审过程中发现的疑似异常行为
- 为监管部门提供评审过程的可追溯依据
- 为质疑投诉处理和行政处罚提供证据支撑
- 为评审专家管理和信用评价提供数据参考

### 1.2 报告生成方式

- **自动生成**：评审结束后系统自动生成，无需人工干预
- **数据来源**：视频行为识别记录 + 音频敏感词监测记录 + 系统操作日志 + 预警处置记录
- **生成时间**：评审结束后5分钟内生成初稿，支持人工补充和确认
- **存档方式**：报告自动存档于"远程评审监控系统"数据库，原始记录可追溯查询

### 1.3 报告编号规则

报告编号格式：`CG-YYYY-XXXX`
- `CG`：采购（CaiGou）缩写
- `YYYY`：年份
- `XXXX`：当年流水号（4位，从0001开始）

示例：`CG-2026-0023` 表示2026年第23份异常行为分析报告

---

## 二、报告模板结构

报告共分为四个部分：
1. 项目基本信息
2. 疑似异常行为分析
3. 活跃视频时段记录
4. 综合结论

### 6.4 处理建议

根据异常行为的严重程度，系统给出处理建议：

**轻微异常（黄色预警）：**
- 已通过系统实时预警提醒
- 记录在案，作为专家评审行为参考
- 无需进一步处置

**建议人工复核异常（橙色警示）：**
- 建议监管人员人工复核相关音视频片段
- 复核确认违规的，按相关规定处理
- 复核确认为误报的，撤销预警记录

**重大疑似违规（红色警报）：**
- 建议立即启动调查程序
- 调取完整证据包（音视频片段+转写文字+系统日志）
- 按政府采购相关法律法规处理
- 涉及违法的，移交有关部门

## 七、报告生成流程

### 7.1 自动生成步骤

```
评审结束
    ↓
1. 数据汇总（视频行为记录+音频敏感词记录+系统日志+预警记录）
    ↓
2. 异常行为分类整理（按5大类分类，去重、合并）
    ↓
3. 活跃时段识别（从监控数据中提取有效工作时段）
    ↓
4. 统计分析（异常数量、分类统计、预警处置统计）
    ↓
5. 报告生成（按模板填充数据，生成结构化报告）
    ↓
6. 报告存档（加密存储，关联项目档案）
    ↓
7. 通知推送（向监管人员推送报告生成通知）
```

### 7.2 人工确认与补充

报告生成后，支持人工确认和补充：
- 监管人员可查看报告并确认异常行为
- 可补充人工发现的异常行为（系统未检测到的）
- 可对系统误报进行标注和撤销
- 确认后的报告作为正式报告存档

### 7.3 报告导出与分享

- 支持导出为PDF、Word格式
- 支持打印（含水印和防伪标识）
- 支持按权限分享给相关人员
- 报告访问全程留痕

## 八、数据安全与隐私保护

### 8.1 数据安全

- 报告及相关音视频数据加密存储
- 访问权限严格控制，仅授权人员可查看
- 报告访问全程留痕，支持审计追溯
- 数据存储周期符合《电子档案管理规范》GB/T 18894（≥10年）

### 8.2 隐私保护

- 专家个人信息按保密要求脱敏处理
- 音视频数据仅用于评审监管目的，不得挪作他用
- 项目结束后按规定期限保存，到期后按规定销毁
- 遵守《个人信息保护法》等相关法律法规

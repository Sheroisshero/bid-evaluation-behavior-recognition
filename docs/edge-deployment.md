# 边缘算力私有化部署方案

## 部署原则

1. **数据不上云**：所有音视频数据、评审数据本地留存，不出中心网络
2. **硬件加密**：AI芯片支持硬件级加密，数据存储和传输全程加密
3. **内外网隔离**：双网卡设计，评审网络与办公网络物理隔离
4. **国产化适配**：全链路国产算力、国产模型、国产操作系统，符合信创要求
5. **可复制推广**：标准化部署方案，支持快速复制到各地公共资源交易中心

## 硬件配置

### AI算力芯片 DF16

| 参数 | 规格 |
|------|------|
| 算力 | 32TOPS（INT8） |
| 等效算力 | ≈30台高性能电脑 |
| 加密 | 硬件级自动加密 |
| 网络 | 双网卡（内外网隔离） |
| 功耗 | 低功耗设计 |
| 部署方式 | 边缘设备/服务器插卡 |

**DF16承担的计算任务**：
- 目标检测推理（YOLOv8，多路视频实时）
- 时序行为识别推理（SlowFast）
- 语音识别推理（ASR）
- 敏感词匹配
- 多模态融合计算
- 视频编码/剪辑

### 智能相机 SC16

| 参数 | 规格 |
|------|------|
| 摄像头 | 全景+特写双路 |
| 分辨率 | 高清（1080P及以上） |
| 帧率 | 全帧率录制，5fps抽帧推理 |
| 安装方式 | 吸顶/壁挂 |
| 覆盖 | 全景覆盖评审室，特写覆盖每个专家席位 |
| 夜视 | 低光照环境适配 |

### 吸顶天花麦 MC16

| 参数 | 规格 |
|------|------|
| 通道 | 多路（每个专家席位独立麦克风） |
| 采样率 | 高清音频采样 |
| 降噪 | 环境噪声抑制 |
| 声源定位 | 辅助判断发言专家位置 |
| 安装方式 | 吸顶 |
| 覆盖 | 全评审室无死角 |

### 部署规模（中心试点）

约30台设备配置至中心：
- AI算力芯片DF16：1台（主算力）
- 智能相机SC16：多台（按评审室数量和规模）
- 吸顶天花麦MC16：多台（按评审席位数量）
- 智能评审终端：按评审席位配置
- 网络设备：交换机、路由器等
- 存储设备：本地NAS/服务器（音视频存档）

### 网络隔离策略

1. **物理隔离**：评审网络使用独立交换机，与办公网络物理分离
2. **双网卡**：DF16芯片和应用服务器配置双网卡，分别连接评审网络和办公网络
3. **单向同步**：评审数据通过防火墙单向同步至办公网络（仅同步报告和统计数据，不同步原始音视频）
4. **访问控制**：评审网络仅允许授权设备接入，MAC地址白名单
5. **数据留存**：原始音视频数据仅存储在评审网络内的本地存储，不允许外发

## 数据安全

### 数据加密
- **存储加密**：音视频文件、数据库加密存储（DF16硬件加密）
- **传输加密**：网络传输使用TLS加密
- **密钥管理**：硬件安全模块（HSM）管理加密密钥

### 访问控制
- **RBAC权限管理**：基于角色的访问控制，不同角色（管理员/见证人员/审计人员）权限不同
- **操作审计**：所有数据访问、导出、删除操作记录审计日志
- **数据脱敏**：专家姓名、身份证号等个人信息脱敏处理

### 数据留存与销毁
- **留存周期**：按政府采购法规要求留存（通常不少于15年）
- **到期销毁**：留存期满后，按数据销毁流程安全销毁
- **备份策略**：本地备份+异地备份（加密后），防止数据丢失

## 双场景支持

### 本地评审场景
- 评审专家在中心评审室现场评审
- 智能相机、天花麦直接采集现场音视频
- DF16本地实时推理
- 见证人员在监控室实时监控

### 远程异地评审场景
- 评审专家分布在不同地点（本地+远程）
- 各评审节点部署相同的边缘设备
- 各节点本地推理，异常事件汇总至中心平台
- 支持跨节点的异常事件关联分析
- 作为远程异地评标节点，可推广至全国各地公共资源交易中心及社会代理机构

## 部署流程（标准化）

1. **现场勘查**：评审室布局、网络条件、电力条件
2. **方案设计**：设备数量、安装位置、网络拓扑
3. **设备安装**：相机、麦克风、终端、算力设备安装调试
4. **系统部署**：操作系统、AI模型、应用服务部署
5. **模型适配**：针对现场环境（光照、声学）微调模型
6. **测试验收**：功能测试、性能测试、安全测试
7. **人员培训**：见证人员、管理员操作培训
8. **正式上线**：投入使用，持续优化

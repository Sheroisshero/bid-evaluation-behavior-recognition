# 合作创新采购模式详解

> 本文档详细介绍本项目采用的合作创新采购方式（财库〔2024〕13号），包括政策依据、模式特点、风险共担机制、成果共享机制、联合推广计划等，展示政企联合研发的创新实践。

---

## 一、政策依据

### 1.1 国家政策

本项目严格按照财政部《政府采购合作创新采购管理暂行办法》（财库〔2024〕13号）执行，该办法是国家为推动政府采购支持科技创新而出台的重要政策文件。

**政策核心要点：**
- 合作创新采购是指采购人就尚未在市场上出现的创新产品，与研发供应商开展合作研发，并首购研发成果的采购方式
- 遵循"风险共担、成果共享"原则
- 适用于市场上尚无成熟产品、需要联合研发的创新项目
- 研发成本补偿 + 首购费用 + 激励费用的费用结构

### 1.2 地方政策

- 《广东省政府采购评审专家管理实施办法》（粤财规〔2025〕1号）：对于采购预算1000万元以上、技术复杂或专家资源稀缺的项目，应当至少抽取1名异地专家，鼓励开展远程异地评标
- 《数字中国建设整体布局规划》：推动招标投标领域全流程数字化转型，加快构建跨区域协同的智能评审体系
- 《国家发展改革委等部门关于加快招标投标领域人工智能推广应用的实施意见》（发改法规〔2026〕195号）：推进招标投标数智化转型升级，提出20个重点应用场景

## 二、项目概况

### 2.1 基本信息

| 项目 | 内容 |
|------|------|
| 项目名称 | 远程异地评审智慧解决方案合作创新采购项目 |
| 采购单位 | 广州市政府采购中心 |
| 研发供应商 | 视源股份（MAXHUB） |
| 项目类型 | 服务类（合作创新采购） |
| 最高研发费用 | 42.586万元人民币 |
| 资金类型 | 自有资金 |
| 采购方式 | 合作创新采购（两阶段评审） |
| 研发期限 | 60个自然日研发 + 30天迭代 + 30天首购交付 |

### 2.2 项目背景

根据《广东省政府采购评审专家管理实施办法》要求，对于采购预算1000万元以上、技术复杂或专家资源稀缺的项目，应当至少抽取1名异地专家，鼓励开展远程异地评标。

为落实该要求，同时响应合作创新采购"风险共担、成果共享"的创新采购理念，广州市政府采购中心计划通过合作创新采购方式，研发一套集成音视频交互、智能行为分析、多场景适配的远程异地评审智慧解决方案。

**行业痛点：**
- 广东省远程异地评标系统普及率仅35%，低于江浙地区52%
- 现有系统多缺乏针对评审专家异常行为的智能识别功能
- 传统远程评审仅能实现音视频记录，异常行为需人工回看排查
- 不同供应商系统接口不兼容，影响跨区域协同评审效率

## 三、合作创新采购模式特点

### 3.1 风险共担机制

**研发风险共担：**
- 采购人支付研发成本补偿费用（3万元），补偿供应商研发投入
- 供应商承担研发失败的主要技术风险
- 分阶段验收，未通过验收时支付研发成本补偿，通过验收后支付首购费用
- 技术风险应对：分阶段验证算法测试报告，关键模块提供备用方案

**市场风险共担：**
- 采购人预留10%首购金额应对政策变动
- 动态监测竞品，若同类产品功能覆盖≥80%可启动合同终止
- 敏捷迭代条款，预留快速响应预算用于政策变动导致的紧急功能调整

**履约风险共担：**
- 里程碑付款，按研发进度分期支付
- 需求变更需双方书面确认，单次变更成本增加超10%时重新议价
- 退出机制：双方均可在特定条件下终止合同，按实际完成工作量结算

### 3.2 成果共享机制

**知识产权共享：**
- 项目研发中产生的所有知识产权（含软件著作权、发明专利等），由采购人与供应商共同拥有
- 采购人支付首购费用后，享有永久免费使用权及推广权
- 如遇国家重大公共利益需求，双方协商调整权属

**利益分配：**
- **研发阶段**：采购人支付研发成本补偿费用，不参与研发过程利益分配
- **联合推广阶段**：联合向其他单位推广产品，推广费用及占比另行商议，不低于市场报价10%，双方共同拥有商业化权利

**使用机制：**
- **采购人权利**：永久免费使用权、升级权、本地化部署权，可进行非核心功能二次开发
- **供应商权利**：可将研发成果作为自身技术成果宣传、参展、申请奖项（使用采购人名称需书面同意）
- **保密义务**：双方对对方商业秘密、技术信息保密
- **转让限制**：供应商转让知识产权需提前30天书面通知采购人，受让方需继续履行采购人免费使用权

### 3.3 两阶段评审机制

本项目采用综合评分法，对供应商响应文件采取**两阶段评审**：

**第一阶段：研发方案评审（60分）**
- 技术可行性（20分）：方案与需求匹配度、技术路线成熟度、验证成果
- 创新性（15分）：技术创新点、知识产权、行业领先性
- 实施计划（15分）：进度安排、资源配置、风险管理
- 团队能力（10分）：核心成员经验、团队配置、稳定性

研发方案得分排名前3名的供应商进入第二阶段。

**第二阶段：综合评审（40分）**
- 研发成本补偿金额报价（3分）：低价优先法
- 首购产品金额报价（10分）：低价优先法
- 研发完成时间（3分）：提前完成得3分，按期完成得2分
- 售后服务方案（8分）：响应时效、服务完整性、增值服务
- 供应商实力（16分）：相关资质证书

最终按照两阶段得分总和从高到低排序，确定最多两名成交候选人。

## 四、费用结构与支付方式

### 4.1 费用结构

| 费用类别 | 金额（万元） | 说明 |
|---------|------------|------|
| 最高研发费用 | 42.586 | 包含研发成本补偿、首购、激励及其他费用 |
| 其中：研发成本补偿费用 | 3 | 未通过验收时支付，补偿直接成本及合理间接费用 |
| 其中：创新产品首购费用 | 42.586 | 通过验收并确定为首购产品时支付 |
| 激励费用 | 含在首购费用中 | 研发提前完成且核心功能达标时支付 |

### 4.2 研发成本补偿范围

**可补偿的直接成本：**
- 设备费：研发所需计算机、服务器、音视频采集设备等硬件购置或租赁，软件开发工具授权
- 业务费：耗材采购费、测试费（含第三方检测）、技术调研费、专家咨询费
- 劳务费：直接参与研发的技术人员（程序员、测试工程师等）劳务报酬，按实际参与时长计算
- 间接费用：水电费、网络费、场地租赁费等，按直接成本总额的15%以内计取

**不纳入补偿范围：**
- 供应商日常运营成本
- 市场推广费用
- 与本项目研发无关的设备购置费用
- 逾期违约金

### 4.3 支付方式

**研发成本补偿费用（分两期）：**
- 第一期：研发合同签订后10个工作日内，支付50%，作为研发启动资金
- 第二期：完成研发阶段任务并通过中期验收后10个工作日内，支付剩余50%

**首购费用：**
- 研发完成并通过最终验收、确定为首购产品后支付
- 验收标准：功能测试通过率≥98%、行为识别准确率≥95%

**激励费用：**
- 支付条件：研发提前完成（总周期≤162天）且核心功能达标率100%
- 含在首购费用中，不单独支付

## 五、研发周期与里程碑

### 5.1 研发期限

| 阶段 | 期限 | 工作内容 | 交付物 |
|------|------|---------|--------|
| 创新产品研发 | 60个自然日 | 系统核心功能开发、内部测试、初步试运行 | 可演示的完整版本、需求规格说明书、源代码 |
| 迭代升级 | 30个自然日 | 根据反馈完成2轮功能迭代优化 | 优化版本、迭代报告 |
| 首购交付 | 30个自然日 | 最终版本部署、用户培训、第三方检测、验收交付 | 最终版本、操作手册、检测报告、验收报告 |

### 5.2 关键里程碑

| 时间节点 | 工作内容 |
|---------|---------|
| 研发启动后第45天 | 研发中期谈判（进度匹配度、标志性成果、后续调整） |
| 研发启动后第60天 | 研发完成验收（核心功能开发、内部测试、初步试运行） |
| 研发完成后30天 | 迭代升级完成（2轮功能迭代优化） |
| 迭代完成后30天 | 首购交付验收（最终部署、培训、第三方检测、验收） |

### 5.3 中期谈判

研发启动后第45个自然日，组织谈判小组与研发供应商开展一次研发中期谈判：

**谈判内容：**
- 研发进度与计划的匹配度
- 已完成的标志性成果（如音视频模块开发情况）
- 后续研发重点调整
- 成本支出合理性
- 存在的问题及解决方案

**谈判成果：**
- 形成《研发中期谈判纪要》，明确后续工作要求
- 若进度滞后，确定追赶措施及新时间节点
- 若需调整研发内容，同步修改合同相关条款

## 六、验收标准与履约保障

### 6.1 验收标准

**功能验收：**
- 功能测试通过率≥98%
- 核心功能（视频行为识别、音频敏感词监测、多模态融合、三级预警、报告生成）全部达标
- 系统兼容性测试通过（支持多种终端、操作系统）

**性能验收：**
- 异常行为识别准确率≥95%
- 视频行为检测延迟≤200ms
- 音频转写延迟≤1秒
- 音视频交互延迟≤100ms
- 并发评审支持≥10组
- 系统可用性≥99.9%

**安全验收：**
- 通过国家网络安全等级保护（二级或三级）测评
- 数据加密传输和存储
- 权限隔离和操作留痕
- 符合《电子档案管理规范》GB/T 18894

**文档验收：**
- 需求规格说明书
- 系统设计文档
- 源代码（含注释）
- 测试报告
- 操作手册
- 第三方检测报告

### 6.2 履约保障

**运维服务：**
- 自首购交付验收合格起，供应商提供终生免费运维服务
- 7×24小时技术支持，故障响应时间≤1小时
- 广东省内设立常驻技术支持团队

**升级服务：**
- 自首购交付验收合格之日起6个月免费迭代升级
- 升级内容：功能性升级、性能优化、安全升级
- 免费期后年度升级费用不超过首购金额的10%
- 供应商每季度提交升级计划，避开评标高峰期实施

**本地化服务：**
- 供应商在广东省内设立常驻技术支持团队
- 关键设备优先采用国产化硬件
- 兼容鸿蒙/麒麟等自主操作系统

**风险管控：**
- 技术风险：分阶段提交算法测试报告，关键模块提供备用方案
- 市场风险：预留10%首购金额应对政策变动
- 履约风险：里程碑付款，需求变更书面确认并重新议价
- 退出机制：双方均可在特定条件下终止合同

## 七、联合推广计划

### 7.1 推广目标

项目研发成功后，计划由广州市政府采购中心与视源股份联合推广，将远程异地评审智慧解决方案推广至：

- **全国各地公共资源交易中心**：作为远程异地评标节点的智慧监管基础设施
- **社会代理机构**：为招标代理机构提供远程评标智慧监管解决方案
- **政府采购中心**：全国各省市政府采购中心
- **国企采购平台**：大型国有企业的采购平台

### 7.2 推广模式

**联合推广机制：**
- 采购人与供应商联合向其他单位推广产品
- 推广费用及占比由双方另行商议，不低于市场报价10%
- 双方共同拥有研发成果的商业化权利（向其他交易中心销售、授权使用等）

**推广策略：**
1. **示范先行**：以广州市政府采购中心为示范基地，形成可复制、可推广的经验做法
2. **区域拓展**：先广东省内，再长三角、京津冀，逐步向全国推广
3. **生态合作**：与各地公共资源交易中心建立战略合作，共建远程评标节点网络
4. **标准引领**：依托广东省采购服务标准化技术委员会（GD/TC 121），主导制定行业标准

### 7.3 推广价值

**对行业：**
- 提升远程异地评标系统普及率（广东省从35%提升至50%以上）
- 推动评审监管从"事后抽查"升级为"实时全覆盖"
- 为行业标准制定提供实践基础
- 树立政府采购智慧监管的广州样板

**对采购人：**
- 通过联合推广获得收益分成
- 提升广州市政府采购中心的行业影响力
- 为政府采购数字化转型提供示范
- 吸引更多专家资源，提升评审质量

**对供应商：**
- 获得政府采购领域的标杆案例
- 拓展政企市场，提升品牌影响力
- 获得持续的运维和升级服务收入
- 技术成果在更多场景中迭代优化

## 八、项目创新点

### 8.1 采购模式创新

- 全国首批采用合作创新采购方式的政府采购智慧监管项目
- "风险共担、成果共享"机制的实践探索
- 两阶段评审机制的创新应用
- 政企联合研发、联合推广的新模式

### 8.2 技术创新

- 全国首个面向政府采购远程异地评标场景的多模态AI异常行为识别系统
- 视频+音频+日志三路多模态融合的异常行为检测架构
- 政府采购评审场景专用的四大类违禁词库
- 黄/橙/红三级递进式预警机制
- 边缘AI+集中运算融合的私有化部署架构

### 8.3 应用创新

- 评审过程从"人工监控"升级为"AI实时监管"
- 异常行为从"事后追溯"升级为"事中预警"
- 评审报告从"人工撰写"升级为"自动生成"
- 监管证据从"零散记录"升级为"结构化证据包"
